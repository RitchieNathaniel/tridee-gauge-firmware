# tridee-gauge-firmware

Repo distribusi firmware **produksi** RevQ Smart Gauge by Tridee Studio (build
`s3_gauge`, tabel partisi `0x10000`). Berisi `latest-pt10000.json` +
`firmware-pt10000.tfw` bertanda tangan kunci produksi Tridee; gauge pembeli
menolak paket lain. Ini repo distribusi, bukan source code.
